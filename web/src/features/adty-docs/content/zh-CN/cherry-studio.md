# Cherry Studio

1. 打开 **设置 → 模型服务**，点底部的 **添加**，名称填 `ADTY AI`，提供商类型选 **OpenAI**。
2. 填写：

| 字段 | 值 |
|---|---|
| API 密钥 | `sk-你的密钥` |
| API 地址 | `{{BASE_URL}}` |

3. 点 **检测** 测试密钥，然后打开这个服务商的开关。
4. 在模型列表下点 **管理**（或 **添加**），按[模型价格](/pricing)页里的名字添加想用的模型，例如 `claude-sonnet-4-5`、`gpt-4o-mini`。
5. 在对话顶部选中模型，就可以开始聊天。

## 注意

- API 地址不要带 `/v1`，Cherry Studio 会自己补上 `/v1/chat/completions`。如果请求报 404，检查地址末尾是不是多了 `/v1`。
- 检测报 401：密钥填错了或已停用。报 403：余额用完了，或者这个密钥不能用该模型。详见[错误码和限制](/docs/errors-and-limits)。
