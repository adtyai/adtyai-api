# Cherry Studio

1. 開啟 **設定 → 模型服務**，點底部的 **新增**，名稱填 `ADTY AI`，供應商類型選 **OpenAI**。
2. 填寫：

| 欄位 | 值 |
|---|---|
| API 金鑰 | `sk-你的金鑰` |
| API 位址 | `{{BASE_URL}}` |

3. 點 **檢查** 測試金鑰，然後打開這個供應商的開關。
4. 在模型列表下點 **管理**（或 **新增**），按[模型價格](/pricing)頁裡的名稱加入想用的模型，例如 `claude-sonnet-4-5`、`gpt-4o-mini`。
5. 在對話頂部選好模型，就可以開始聊天。

## 注意

- API 位址不要帶 `/v1`，Cherry Studio 會自己補上 `/v1/chat/completions`。如果請求回 404，檢查位址結尾是不是多了 `/v1`。
- 檢查回 401：金鑰填錯了或已停用。回 403：餘額用完了，或者這把金鑰不能用該模型。詳見[錯誤碼和限制](/docs/errors-and-limits)。
