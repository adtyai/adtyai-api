# Cherry Studio

1. **設定 → モデルプロバイダー** を開き、下部の **追加** をクリックします。名前に `ADTY AI` と入力し、プロバイダーの種類で **OpenAI** を選びます。
2. 次のように入力します。

| 項目 | 値 |
|---|---|
| API キー | `sk-あなたのキー` |
| API ホスト | `{{BASE_URL}}` |

3. **チェック** をクリックしてキーをテストし、プロバイダーをオンにします。
4. モデル一覧の下にある **管理**（または **追加**）をクリックし、使いたいモデルを[料金](/pricing)ページの名前で追加します。たとえば `claude-sonnet-4-5` や `gpt-4o-mini` です。
5. チャット画面の上部でモデルを選び、会話を始めます。

## ヒント

- API ホストは `/v1` を付けずに入力します。Cherry Studio が `/v1/chat/completions` を自動で付け加えます。リクエストが 404 で失敗する場合は、ホストの末尾が `/v1` になっていないか確認してください。
- チェックが 401 で失敗する場合：キーが間違っているか、無効になっています。403 で失敗する場合：残高がなくなったか、そのキーではそのモデルを使えません。[エラーと制限](/docs/errors-and-limits)を参照してください。
