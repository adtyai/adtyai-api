# エラーと制限

エラーは OpenAI 形式で返ります。HTTP ステータスコードと、`error.message` と `error.code` を含む JSON 本文です。メッセージは何が問題だったかを示し、ステータスコードはどう対処すべきかを示します。

## ステータスコード

| コード | 意味 | 対処 |
|---|---|---|
| 400 | リクエストが不正です。たとえば本文の形式が誤っている、またはモデルが受け付けないパラメーターが含まれています | リクエストを修正してください。同じリクエストを再試行しても再び失敗します |
| 401 | API キーがない、間違っている、無効化されている、期限切れ、またはキー自体の上限額を使い切っています | `Authorization: Bearer sk-...` ヘッダーと、[API キー](/keys)ページでキーの状態を確認してください |
| 402 | 支払いが必要です。ADTY AI は残高不足を 403（下記）で返すため、402 は通常、上流のプロバイダーから返されたものです | しばらくしてから再試行してください。解決しない場合はサポートに連絡してください |
| 403 | 残高が不足している（`insufficient_user_quota`）か、そのキーではこのモデルまたはグループを使えません | [チャージ](/wallet)するか、キーのモデルとグループの設定を確認してください |
| 404 | パスが間違っているか、モデルが存在しません | アドレス（`/v1` を含めるかどうかは各クライアントのガイドを参照）と、[料金](/pricing)ページのモデル名を確認してください |
| 429 | アカウントのリクエストが多すぎる（`rate_limit_exceeded`）か、上流が混み合っています | 待ってから再試行してください。下記の制限を参照してください |
| 500, 502, 503 | 上流のプロバイダーで障害が起きたか、そのモデルに使えるチャネルがありません | 間隔を空けて再試行してください。解決しない場合はサポートに連絡してください |
| 524 | リクエストに時間がかかりすぎ、接続が切断されました（下記参照） | ストリーミングを使ってください |

エラーで拒否されたリクエストは課金されません。

## アカウントごとの制限

アカウントには次の 3 つの制限を設定できます。いずれも、そのアカウントのすべてのキーを合計して数えます。

- **RPM**：1 分あたりのリクエスト数。
- **TPM**：1 分あたりのトークン数。
- **同時実行数**：同時に処理中のリクエスト数。

どれかを超えると 429 が返り、何秒待てばよいかを示す `Retry-After` ヘッダーが付きます。すぐに再試行せず、その時間が過ぎてから再試行してください。より高い制限が必要な場合は、サポートに連絡してください。

## 長いリクエストにはストリーミングを使う

通信は Cloudflare を経由します。Cloudflare は、約 **125 秒**間何もデータが送られない接続を切断します。それより長くかかる非ストリーミングのリクエスト（長い出力、推論モデル、大きなコード編集など）は途中で切断され、モデルがまだ処理中でもクライアントにはエラー（通常は 524）が表示されます。

`"stream": true` を設定してください。ストリーミングのレスポンスはすぐにデータを送り始め、モデルが完了するまで接続を維持します。Claude Code、Codex CLI、ほとんどのチャットクライアントは、デフォルトでストリーミングを使います。
