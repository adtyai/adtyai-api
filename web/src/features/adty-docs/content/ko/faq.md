# 자주 묻는 질문

## 어떻게 충전하나요?

[지갑](/wallet)을 열고 금액과 결제 수단(사용 설정된 USDT, Alipay 또는 WeChat Pay)을 고른 뒤 열린 창에서 결제하세요. 결제가 확인되면 잔액이 자동으로 들어옵니다. 페이지에 머무를 필요는 없습니다. 최소 금액과 충전 보너스는 지갑 페이지에 표시됩니다.

## 결제는 됐는데 잔액이 변하지 않습니다

USDT는 네트워크가 이체를 확인한 뒤에 입금되며 몇 분이 걸릴 수 있습니다. Alipay와 WeChat Pay는 보통 1분 안에 입금됩니다. 30분이 지나도 잔액이 변하지 않으면 [지갑](/wallet)에 표시된 주문 번호와 함께 지원팀에 문의하세요.

## 요금은 어떻게 계산되나요?

사용한 만큼 냅니다. 각 요청은 사용한 토큰(일부 모델은 호출당 또는 이미지당)에 따라 [가격](/pricing) 페이지의 가격으로 청구됩니다. [사용 로그](/usage-logs)에서 요청마다 비용을 볼 수 있습니다. 월 이용료는 없습니다.

## 세금계산서를 발행하나요?

아닙니다. ADTY AI는 세금계산서나 VAT 영수증을 발행하지 않습니다. [지갑](/wallet)의 주문 내역과 사용 로그가 제공하는 기록입니다.

## 환불받을 수 있나요?

[환불 정책](/refund-policy)을 보세요.

## 어떤 모델을 쓸 수 있나요?

[가격](/pricing) 페이지의 모든 모델입니다. 거기에 표시된 모델 이름을 그대로 사용하세요. 키 하나로 모두 호출할 수 있습니다.

## 키 하나를 여러 도구에서 쓸 수 있나요?

가능합니다. 다만 [API 키](/keys) 페이지에서 도구마다 키를 만드는 편이 낫습니다. 도구별 사용량을 따로 보고, 다른 도구에 영향 없이 하나만 끌 수 있습니다.

## 데이터가 저장되나요?

요청은 응답을 만들기 위해 모델 제공자에게 전달됩니다. 콘솔의 사용 로그에는 각 요청의 모델, 토큰, 비용이 남습니다. 무엇을 얼마나 보관하는지는 [개인정보 처리방침](/privacy-policy)에 있습니다.

## 추천으로 어떻게 수익을 내나요?

[제휴 프로그램](/affiliate)에 참여해 링크를 공유하면, 초대한 사람의 충전에 대해 커미션을 받습니다.

## 그래도 도움이 필요합니다

페이지 아래쪽 링크로 지원팀에 문의하세요.
