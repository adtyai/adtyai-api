# 오류와 한도

오류는 OpenAI 형식입니다. HTTP 상태 코드와 `error.message`, `error.code`가 있는 JSON 본문입니다. 메시지는 무엇이 잘못됐는지, 상태 코드는 다음에 무엇을 할지를 알려 줍니다.

## 상태 코드

| 코드 | 의미 | 할 일 |
|---|---|---|
| 400 | 요청이 잘못되었습니다. 본문 형식 오류나 모델이 받지 않는 매개변수 | 요청을 고치세요. 같은 요청을 다시 보내도 실패합니다 |
| 401 | API 키가 없거나 틀리거나 꺼졌거나 만료됐거나 키 자체 한도를 썼습니다 | `Authorization: Bearer sk-...` 헤더와 [API 키](/keys) 페이지의 키 상태를 확인하세요 |
| 402 | 결제가 필요합니다. ADTY AI는 잔액 부족을 403으로 알리므로 402는 보통 업스트림에서 옵니다 | 나중에 다시 시도하고, 계속되면 지원팀에 문의하세요 |
| 403 | 잔액이 부족하거나(`insufficient_user_quota`) 키가 이 모델이나 그룹을 쓸 수 없습니다 | [충전](/wallet)하거나 키의 모델과 그룹 설정을 확인하세요 |
| 404 | 경로가 잘못됐거나 모델이 없습니다 | 주소에 `/v1`이 필요한지와 [가격](/pricing) 페이지의 모델 이름을 확인하세요 |
| 429 | 계정 요청이 너무 많거나(`rate_limit_exceeded`) 업스트림이 바쁩니다 | 기다렸다가 다시 시도하세요. 아래 한도를 보세요 |
| 500, 502, 503 | 업스트림이 실패했거나 이 모델에 쓸 채널이 없습니다 | 간격을 두고 재시도하고, 계속되면 지원팀에 문의하세요 |
| 524 | 요청이 너무 오래 걸려 연결이 끊겼습니다 | 스트리밍을 사용하세요 |

오류로 거절된 요청은 청구되지 않습니다.

## 계정당 한도

계정에는 모든 키를 합쳐 세 가지 한도가 있을 수 있습니다.

- **RPM**: 분당 요청 수.
- **TPM**: 분당 토큰 수.
- **동시 실행**: 동시에 진행 중인 요청 수.

한도를 넘으면 429와 함께 몇 초를 기다려야 하는지 적힌 `Retry-After` 헤더가 옵니다. 바로 다시 보내지 말고 그 시간 뒤에 재시도하세요. 더 높은 한도가 필요하면 지원팀에 문의하세요.

## 긴 요청은 스트리밍을 사용하세요

트래픽은 Cloudflare를 지납니다. 약 **125초** 동안 아무 데이터도 없으면 연결이 끊깁니다. 그보다 오래 걸리는 비스트리밍 요청(긴 출력, 추론 모델, 큰 코드 수정)은 모델이 아직 작업 중이어도 보통 524로 끊깁니다.

`"stream": true`로 설정하세요. 스트리밍 응답은 바로 데이터를 보내 모델이 끝날 때까지 연결을 유지합니다. Claude Code, Codex CLI와 대부분의 채팅 클라이언트는 기본적으로 스트리밍합니다.
