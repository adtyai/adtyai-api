# Cherry Studio

1. Откройте **Настройки → Провайдеры моделей**, нажмите **Добавить** внизу, введите `ADTY AI` в качестве названия и выберите **OpenAI** в качестве типа провайдера.
2. Заполните поля:

| Поле | Значение |
|---|---|
| API-ключ | `sk-ваш-ключ` |
| Адрес API | `{{BASE_URL}}` |

3. Нажмите **Проверить**, чтобы проверить ключ, затем включите провайдера.
4. Нажмите **Управление** (или **Добавить**) под списком моделей и добавьте нужные модели, используя названия со страницы [Цены](/pricing), например `claude-sonnet-4-5` или `gpt-4o-mini`.
5. Выберите модель в верхней части чата и начните общение.

## Советы

- Вводите адрес API без `/v1`: Cherry Studio сам добавляет `/v1/chat/completions`. Если запросы завершаются ошибкой 404, проверьте, что адрес не заканчивается на `/v1`.
- Проверка завершается ошибкой 401: ключ неверен или отключён. Проверка завершается ошибкой 403: закончился баланс или ключу не разрешено использовать эту модель. См. [Ошибки и лимиты](/docs/errors-and-limits).
