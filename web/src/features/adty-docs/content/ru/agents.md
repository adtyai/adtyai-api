# Агенты

Вызывайте модель с инструментами через клиент, совместимый с OpenAI. Базовый адрес — `{{BASE_URL}}/v1`, ключ — ключ ADTY AI. Цикл агента остается в вашей программе: сайт возвращает вызов инструмента, а результат вы отправляете следующим запросом.

```python
from openai import OpenAI

client = OpenAI(base_url="{{BASE_URL}}/v1", api_key="sk-your-key")
```

Ключ тарифицируется как обычный ключ API. Им нельзя читать кошелек или входить в аккаунт.
