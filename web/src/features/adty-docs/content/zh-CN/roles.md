# 角色使用说明

## 普通用户

注册后在钱包查看美元余额、本金和赠金。创建 API Key 后，把站点地址和 Key 配到客户端即可调用。

## 团队负责人

创建团队、邀请成员、设置折扣，并用团队共享余额创建团队 Key。退出团队前先移交或关闭团队。

## 团队成员

接受邀请后使用团队 Key。不能同时加入两个团队。退出后团队 Key 不再扣你的个人余额。

## 分站站长

配置品牌、售价和本站赠金。收益进收益钱包，保证金按周期动用。关站前先处理未完成订单。

## 分站员工

只能操作本站客户。余额调整必须提交申请，站长或主站管理员批准后才入账。

## 主站管理员

创建分站、设置供货价和邀请比例。支付、退款和调额都要留下流水，不能直接改余额。
