# 错误码和限制

报错用 OpenAI 的格式：HTTP 状态码，加上带 `error.message` 和 `error.code` 的 JSON。message 说明出了什么问题，状态码告诉你该怎么处理。

## 状态码

| 状态码 | 含义 | 怎么处理 |
|---|---|---|
| 400 | 请求有误，比如请求体格式不对，或者模型不接受某个参数 | 修改请求；原样重试还会失败 |
| 401 | 没带 API 密钥，或者密钥错误、已停用、已过期、密钥自己的额度用完了 | 检查 `Authorization: Bearer sk-...` 请求头，以及[令牌](/keys)页里密钥的状态 |
| 402 | 需要付款。ADTY AI 余额不足时返回的是 403（见下一行），出现 402 一般是上游服务商返回的 | 稍后重试；一直出现请联系客服 |
| 403 | 账户余额不足（`insufficient_user_quota`），或者这个密钥不能用该模型或分组 | [充值](/wallet)，或者检查密钥的模型和分组设置 |
| 404 | 路径错了，或者模型不存在 | 检查地址（要不要带 `/v1` 见各客户端的说明），以及[模型价格](/pricing)页里的模型名 |
| 429 | 你的账号请求太多（`rate_limit_exceeded`），或者上游繁忙 | 等一会儿再试，见下面的限制说明 |
| 500、502、503 | 上游服务商出错，或者这个模型暂时没有可用通道 | 间隔逐渐加长地重试；一直出现请联系客服 |
| 524 | 请求太久，连接被断开（见下文） | 改用流式 |

被拒绝、返回错误的请求不扣费。

## 按账号的限制

账号可能有三项限制，所有密钥合起来计算：

- **RPM**：每分钟请求数。
- **TPM**：每分钟 tokens 数。
- **并发**：同时进行的请求数。

超过任何一项都返回 429，并带 `Retry-After` 响应头，告诉你要等几秒。请等到这个时间再重试，不要马上重试。如果你的业务需要更高的限制，请联系客服。

## 长请求请用流式

请求会经过 Cloudflare。连接上约 **125 秒**没有任何数据，Cloudflare 就会把它断开。非流式请求如果超过这个时间（输出很长、推理模型、大段代码修改），就会被断开，客户端收到报错（通常是 524），哪怕模型其实还在生成。

设置 `"stream": true`。流式响应会马上开始返回数据，并一直保持连接，直到模型生成完。Claude Code、Codex CLI 和大部分聊天客户端默认就是流式。
