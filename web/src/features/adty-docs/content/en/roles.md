# Role guides

## User

After registration, open the wallet to see the USD balance, principal, and bonus. Create an API key and put the site URL and key in the client.

## Team lead

Create a team, invite members, set the discount, and issue a team key against the shared balance. Close or hand over the team before leaving.

## Team member

Accept one invitation and use the team key. A person can belong to only one team. Leaving the team does not charge the personal wallet.

## Site owner

Set the brand, retail price, and site gift. Earnings go to the earnings wallet. Margin draws follow the open cycle. Finish open orders before closing the site.

## Site staff

Work only on customers of this site. A balance change is a request until the owner or a main-site admin approves it.

## Main-site admin

Create sites and set supply prices and invite rates. Payments, refunds, and adjustments must write a ledger row. Do not edit a balance by hand.
