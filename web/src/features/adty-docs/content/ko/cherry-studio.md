# Cherry Studio

1. **설정 → 모델 제공자**를 열고 아래쪽 **추가**를 누른 뒤 이름을 `ADTY AI`로 입력하고 제공자 유형으로 **OpenAI**를 선택하세요.
2. 다음을 입력합니다.

| 필드 | 값 |
|---|---|
| API Key | `sk-your-key` |
| API Host | `{{BASE_URL}}` |

3. **확인**을 눌러 키를 검사한 뒤 제공자를 켜세요.
4. 모델 목록 아래 **관리**(또는 **추가**)를 누르고 [가격](/pricing) 페이지의 이름으로 모델을 추가하세요. 예: `claude-sonnet-4-5`, `gpt-4o-mini`.
5. 채팅 상단에서 모델을 고르고 대화를 시작하세요.

## 참고

- API 호스트에는 `/v1`을 붙이지 마세요. Cherry Studio가 `/v1/chat/completions`를 직접 붙입니다. 404가 나면 호스트가 `/v1`로 끝나지 않는지 확인하세요.
- 확인이 401이면 키가 잘못되었거나 꺼진 상태입니다. 403이면 잔액이 없거나 그 키로 해당 모델을 쓸 수 없습니다. [오류와 한도](/docs/errors-and-limits)를 보세요.
